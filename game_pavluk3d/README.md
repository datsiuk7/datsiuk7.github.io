# Павлик: Дорога додому

Браузерна 3D пригода на Three.js. Павлик досліджує чотири наземні регіони: лісове селище, кам’яний каньйон, гірське містечко й приморський порт. У кожному регіоні треба зібрати п’ять зірок, відкрити портал та випередити сонного дракона.

## Керування

- **WASD** або **стрілки** — рух відносно камери.
- **Shift** — біг; **пробіл** — стрибок.
- Перетягнути мишу — повернути камеру; колесо — змінити відстань.
- На телефоні: джойстик зліва, стрибок справа, жест по сцені повертає камеру.
- **Esc** — пауза; **R** — перезапуск регіону.

## Локальна розробка

```bash
npm install
npm run dev
```

Для статичної публікації через GitHub Pages:

```bash
npm run deploy:pages
```

Ця команда збирає гру з відносними шляхами та копіює `index.html` і ресурси до цієї папки. `index.source.html` — вихідний шаблон для Vite.

3D тіло та голова Павлика створені геометрією Three.js. Фототекстура обличчя `public/assets/pavlyk-portrait.png` створена за наданим фото та накладена на округлу поверхню голови.
