# Крок

Один рівень браузерної 3D-гри з перетягуванням команд. Без меню, звуків і сервера даних. Three.js збережений локально у vendor, зовнішні запити не потрібні.

Запуск: `node server.cjs`, потім відкрити http://127.0.0.1:5173.

Команди можна додавати натисканням або перетягуванням, переставляти перетягуванням і видаляти кнопкою ×. «Скинути» перериває виконання та повертає робота на старт, зберігаючи програму. Кожен запуск починається зі старту.

Розв’язок: уперед, уперед, праворуч, уперед, уперед.
