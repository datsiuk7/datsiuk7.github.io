# Павлик: Світ Хмар 🐸

Повноцінна браузерна 3D пригода на Three.js. Павлик вільно ходить літаючими островами, стрибає між ними, збирає зірки, уникає сонного дракона й відкриває портали трьох зон.

## Запуск для розробки

```bash
npm install
npm run dev
```

Після публікації вихідна сторінка для розробки доступна на локальному Vite сервері за `/index.source.html`.

## Керування

- **WASD** або **стрілки** — рух відносно камери.
- **Пробіл** або кнопка **Стрибок** — стрибок.
- **Shift** — швидкий біг.
- Перетягування на сцені — поворот камери; коліщатко — наближення.
- На телефоні: джойстик ліворуч, кнопка стрибка праворуч, проведення по сцені повертає камеру.
- **Esc** — пауза; **R** — перезапуск поточного рівня.

Збери 5 зірок на кожному острові, а потім зайди в портал. Дракон переслідує Павлика, а падіння забирає одне серце. На кожному рівні 3 серця.

## GitHub Pages

```bash
npm run deploy:pages
```

Команда будує гру з відносними шляхами та кладе готові `index.html` і `assets/` у корінь цієї папки. Додайте їх до Git. Вихідний HTML шаблон зберігається в `index.source.html`, щоб наступні збірки працювали після публікації.

Об’ємна модель Павлика побудована з геометрії Three.js. Її обличчя використовує текстуру з раніше створеного за наданим фото портрета `public/assets/pavlyk-frog.png`.
