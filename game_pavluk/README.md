# Павлик-стрибунець 🐸

Веселий 3D платформер у браузері на Three.js. Павлик автоматично біжить по хмаринках, стрибає, збирає зірочки та втікає від сонного дракона. Є три рівні з різними кольорами неба.

## Запуск

```bash
npm install
npm run dev
```

Відкрийте адресу, яку виведе Vite. Для готової збірки: `npm run build`.

## GitHub Pages

Гру можна розмістити в підпапці сайту, наприклад `game_pavluk/`. Команда

```bash
npm run deploy:pages
```

створює збірку з відносними шляхами та копіює `index.html` і `assets/` у корінь цієї папки. Саме ці файли потрібно додати до Git і опублікувати. Вихідний шаблон сторінки зберігається в `index.source.html`; тому повторна збірка працює й після публікації.

## Керування

- **Пробіл**, **↑**, **W**, кнопка **Стрибок** або натискання на сцену — стрибок.
- Після кнопки **Грати** перший стрибок запускає біг.
- Кнопка **♪** вмикає або вимикає звуки.

Портрет Павлика в костюмі жабки створено на основі наданого користувачем фото та збережено в `public/assets/pavlyk-frog.png`.
